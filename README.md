# dotfiles

Every config for zsh, Neovim, Ghostty, git and Claude Code lives here. The tools still read their usual paths; those paths are symlinks into this folder.

`dots` cds here, `dotfig` opens it in Neovim. If a link breaks: `./link.sh` (or `./link.sh --check` to just look).

Private repo: https://github.com/ken-hin/dotfiles

## New Mac

```bash
git clone https://github.com/ken-hin/dotfiles.git ~/dotfiles && ~/dotfiles/bootstrap.sh
```

`bootstrap.sh` installs Xcode tools, Homebrew and everything in `Brewfile`, Oh My Zsh plus zsh-autosuggestions and zsh-syntax-highlighting, links every config, restores Neovim plugins from `lazy-lock.json`, and clones ECC at the commit in `claude/ecc/ECC_COMMIT` and installs your selection. It then lists what it doesn't install (Claude Code, python.org Python, uv, bun, Docker Desktop, JetBrains Toolbox) and the logins to do by hand (`gh auth login`, `claude`). Safe to re-run.

## Keeping it in sync

Edits land in this repo automatically (the configs *are* these files). Commit and push when you change something: `dots && git add -A && git commit -m "..." && git push`. New Homebrew tools: `brew bundle dump --file=~/dotfiles/Brewfile --force --no-vscode`.

## Layout

| Here | Linked from | What |
| --- | --- | --- |
| `zsh/zshrc` | `~/.zshrc` | Oh My Zsh, plugins, theme settings, aliases, functions |
| `zsh/zprofile` | `~/.zprofile` | PATH |
| `zsh/modern-dark-pro-capsule/` | `~/.oh-my-zsh/custom/themes/modern-dark-pro-capsule.zsh-theme` | Prompt theme with your edits (from dvigo/modern-dark-pro-capsule-ohmyzsh @ 6372ae8; includes `wizard.sh`) |
| `zsh/znt/*.conf` | `~/.config/znt/` | zsh-navigation-tools settings |
| `nvim/` | `~/.config/nvim` | LazyVim config |
| `ghostty/config` | `~/.config/ghostty/config` | Terminal |
| `git/gitconfig`, `git/ignore` | `~/.gitconfig`, `~/.config/git/ignore` | Git identity, LFS, global ignores |
| `claude/settings.json` | `~/.claude/settings.json` | Claude Code settings (`install-ecc.sh` briefly swaps in a real copy because ECC's installer won't write through a link) |
| `claude/ecc/` | — | `install-ecc.sh`, `ecc-skills.txt`, `ecc-agents.txt`, `ECC_COMMIT`: your ECC selection and pinned version |
| `Brewfile` | — | Homebrew taps, formulae and apps |
| `bootstrap.sh` | — | Sets up a new Mac from this repo |
| `vendor/ECC/` | — | ECC source (git clone, not tracked) |
| `docs/` | — | Cheatsheets: `ZSH.md`, `NEOVIM.md`, `CLAUDE-CODE.md`, skills audit |
| `archive/` | — | Old configs from earlier cleanups |
| `link.sh` | — | Creates/repairs every link above |

## Common tasks

| Task | Command |
| --- | --- |
| Edit zsh config | `zfig`, then `zload` |
| Edit Neovim config | `nvfig` |
| Add/remove an ECC skill or agent | Edit `claude/ecc/ecc-skills.txt` / `ecc-agents.txt`, run `claude/ecc/install-ecc.sh` |
| Update ECC | `cd vendor/ECC && git pull && npm install --omit=dev --ignore-scripts && ../../claude/ecc/install-ecc.sh` |
| Check all links | `./link.sh --check` |

## Not in here, on purpose

- `~/.config/gh/hosts.yml` (GitHub token), `~/.claude.json` and Claude history (login and app state), `~/.config/znt/privhist.db` (history).
- Third-party code installed by tools: `~/.oh-my-zsh`, Neovim plugins (`~/.local/share/nvim`), ECC's copied files in `~/.claude/{skills,agents,commands,rules}` (regenerated by `install-ecc.sh`).

## Watch out for

Some tools save by replacing the file, which turns a link back into a plain file: the theme's `wizard.sh` and `omz plugin enable` both rewrite `~/.zshrc`. If that happens, `./link.sh --check` reports it. Copy the new `~/.zshrc` over `zsh/zshrc`, then run `./link.sh`.

Backups from the move (2026-11-13): `~/.dotfiles-backup-20261113/`.
